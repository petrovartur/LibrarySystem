Library Management System - консольное приложение на Java для управления библиотекой.

Программа позволяет:
* Добавлять книги
* Регистрировать читателей
* Выдавать книги читателям
* Принимать возврат книг
* Просматривать книги, находящиеся у читателя
* Искать книги по названию и автору
* Просматривать список доступных книг

Данные хранятся в памяти приложения с использованием коллекций Java (`ArrayList`, `HashMap`).


Запуск программы и выполняемые функции:

Открыть файл:
1. Открыть файл Main.java;
2. Запустить с помощью кнопки Run;
   
Использование меню
После запуска появится меню:
===== LIBRARY =====
1. Add Book - добавить новую книгу
2. Add Reader - добавить нового читателя
3. Borrow Book - выдать книгу читателю
4. Return Book - оформить возврат книги читателем
5. Reader Books - проверить список выданных читателям книг
6. Find Book - поиск книги
7. Available Books - проверить доступные в библиотеке книги
0. Exit - завершить программу
